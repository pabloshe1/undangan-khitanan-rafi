# Undangan Khitanan Rafi (Vite + React + TypeScript)

Edit semua data di `src/config.ts` (jam, nomor WhatsApp, lokasi).
Taruh aset di `public/`: `img/rafi.jpg`, `img/poster.jpg`, opsional `audio/music.mp3`.
Link per tamu: `https://domain-lu.vercel.app/?to=Nama+Tamu`

    npm install
    npm run dev      # lokal
    npm run build    # produksi (output: dist/)

Deploy: push ke GitHub, import di vercel.com. Framework Vite terdeteksi otomatis.
